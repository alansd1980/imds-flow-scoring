Integrated Conclusion (ABC)

About This Tool

This tool implements the ELN iMDS flow cytometry scoring framework for bone marrow immunophenotyping in the diagnostic work-up of suspected MDS.

Five modules are assessed: the Ogata diagnostic score, erythroid aberrancy score, myeloid progenitor aberrancy assessment, granulocyte dysplasia features, and monocyte aberrancy assessment.

The integrated conclusion uses ABC scoring: Category A = no MDS-related immunophenotypic features; Category B = limited immunophenotypic changes associated with MDS; Category C = immunophenotypic features consistent with MDS.

For use by trained haematology laboratory scientists and clinicians. It does not replace expert morphological review, cytogenetic analysis or clinical judgment. No patient data is stored or transmitted; CSV files are processed locally in your browser.

CSV import format

Download the blank template, add one row per case and import it. Comma or semicolon delimiters are accepted, as are decimal commas (6,5) and dates as YYYY-MM-DD or DD/MM/YYYY. Tick-box columns accept 1/0, yes/no, true/false. Blank cells are left empty. Column names are not case-sensitive.
